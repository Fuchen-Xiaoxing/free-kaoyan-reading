# 错题本规范与条目 Schema

## 存储位置与写入原则
- **存储文件**：`错题本.md`（默认存放在 Skill 根目录）。
- **写入规则**：**只追加、不覆盖、不修改历史条目**。一律调用 `scripts/record_error.py` 写入，禁止手工拼写。
- **定位与边界**：错题本仅用于篇末归档沉淀与自主复习，日常讲解过程中不主动查阅、检索或关联历史错题。

## 条目 Schema (YAML frontmatter + 正文)

```markdown
---
id: 2009-T4-Q21
题型: 细节题
error_type: 无对应内容
能力短板: 词汇
解题关键词: 题干定位词
原文定位: 定位句出处（如 L12-13）
错误还原: 我怎么错的、选了哪个选项、为什么这么选
方法论归因: 违背/忽略了哪条方法论原则
教训金句: 一句话教训
---

### 2009-T4-Q21

正文：详细的错误分析与复盘，用方法论术语展开。
```

## 字段说明与约束

| 字段名 | 必填 | 取值约束与说明 |
| :--- | :---: | :--- |
| `id` | 是 | 唯一 ID（年份-篇章-题号，如 `2009-T4-Q21`；重复时脚本自动追加 `-2`, `-3`） |
| `题型` / `question_type` | 是 | 细节题 / 词义题 / 主旨题 / 态度题 / 推理题 / 标题题 / 例证题等 |
| `error_type` | 是 | **必须严格属于 12 类错误类型封闭枚举之一**（见 `references/error-types.md`） |
| `能力短板` / `ability_shortboard` | 是 | **必须严格属于 {词汇, 语法, 主旨} 封闭集合之一** |
| `解题关键词` / `keyword` | 是 | 题干定位词或解题核心切入点 |
| `原文定位` / `location` | 是 | 定位句行号或出处 |
| `错误还原` / `restore` | 是 | 以错题复盘中用户自述思路 + 诊断出的思维误区为准，真实记录，禁止凭空编造 |
| `方法论归因` / `attribution` | 是 | 违背或忽略的方法论原则（如正负态度、重要信息识别等） |
| `教训金句` / `lesson` | 是 | 一句话前瞻教训与应对解法 |
| `正文` / `analysis` | 是 | 详细的错误分析与复盘 |

```json
  }

```
