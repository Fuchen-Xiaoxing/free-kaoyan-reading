# 错题本规范与条目 Schema

## 存储位置与写入原则
- **存储文件与路径**：`错题本.md` 默认安全持久化存储于 **Android 手机公共文档目录**（优先 Open Minis 挂载外部文档 `/var/minis/mounts/Documents/考研英语/错题本.md` 或系统公共文档 `/storage/emulated/0/Documents/考研英语/错题本.md`，支持通过 Obsidian、WPS 或系统文件管理器直接复习；未挂载外部目录时安全保存在沙箱工作区 `/var/minis/workspace/错题本.md`），彻底与 Skill 目录解耦；更新、重新克隆或重装 Skill 绝不丢失历史数据。PC 环境默认存放在 `~/Documents/考研英语/错题本.md`；支持环境变量 `KAOYAN_ERROR_NOTEBOOK` 自定义指定（带路径自愈纠偏）。
- **写入规则**：**只追加、不覆盖、不修改历史条目**。一律通过 `scripts/record_error.py` 写入（自动清理占位符与安全迁移旧数据），禁止手工拼写。
- **定位与边界**：错题本仅用于篇末归档沉淀与自主复习，日常讲解过程中不主动查阅、检索或关联历史错题。

## 条目 Schema (YAML frontmatter + 正文)

```markdown
---
id: 2009-T4-Q21
题型: 细节题
error_type: 无对应内容
能力短板: 词汇
解题关键词: 题干定位词
原文定位: 定位句出处（如 L12-13）
错误还原: 我怎么错的、选了哪个选项、为什么这么选
方法论归因: 违背/忽略了哪条方法论原则
教训金句: 一句话教训
---

### 2009-T4-Q21

正文：详细的错误分析与复盘，用方法论术语展开。
```

## 字段说明与约束

| 字段名 | 必填 | 取值约束与说明 |
| :--- | :---: | :--- |
| `id` | 是 | 唯一 ID（年份-篇章-题号，如 `2009-T4-Q21`；重复时脚本自动追加 `-2`, `-3`） |
| `题型` / `question_type` | 是 | 细节题 / 词义题 / 主旨题 / 态度题 / 推理题 / 标题题 / 例证题等 |
| `error_type` | 是 | **必须严格属于 12 类错误类型封闭枚举之一**（见 `references/error-types.md`） |
| `能力短板` / `ability_shortboard` | 是 | **必须严格属于 {词汇, 语法, 主旨} 封闭集合之一** |
| `解题关键词` / `keyword` | 是 | 题干定位词或解题核心切入点 |
| `原文定位` / `location` | 是 | 定位句行号或出处 |
| `错误还原` / `restore` | 是 | 以错题复盘中用户自述思路 + 诊断出的思维误区为准，真实记录，禁止凭空编造 |
| `方法论归因` / `attribution` | 是 | 违背或忽略的方法论原则（如正负态度、重要信息识别等） |
| `教训金句` / `lesson` | 是 | 一句话前瞻教训与应对解法 |
| `正文` / `analysis` | 是 | 详细的错误分析与复盘 |
